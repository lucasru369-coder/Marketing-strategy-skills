# Competitor Selection Method

## Build the set
Include direct competitors, indirect substitutes, emerging challengers, and relevant category leaders.

## Selection criteria
- Same audience or use case
- Similar job-to-be-done
- Comparable price or value tier
- Overlap in channel or geography
- Influence on category expectations

## Guardrails
Do not select competitors only because they are famous. Explain exclusions and revisit the set when the market changes.

## Output
A short list with competitor type, rationale, evidence source, and review date.

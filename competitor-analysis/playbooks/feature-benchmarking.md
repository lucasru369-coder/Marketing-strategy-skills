# Feature Benchmarking Playbook

## Steps
1. Define customer-relevant evaluation dimensions.
2. Create consistent definitions for each dimension.
3. Gather evidence from official product pages, documentation, and verified tests.
4. Mark unknowns instead of guessing.
5. Compare meaningful differences, not just feature counts.

## Suggested dimensions
Core capability, usability, compatibility, service, warranty, availability, price, and proof points.

## Interpretation
Connect each difference to audience value and strategic consequence. A feature advantage is not automatically a preference advantage.

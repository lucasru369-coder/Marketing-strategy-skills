# Marketing Strategy Glossary

A shared vocabulary for the frameworks and templates in this repository.

| Term | Working definition |
|---|---|
| Audience segment | A group of people with relevant shared needs, behaviors, or characteristics. |
| Baseline | The reference value used to interpret change in a metric. |
| Brand positioning | The intended place a brand occupies in the minds of a defined audience relative to alternatives. |
| Campaign objective | The specific outcome a campaign is designed to influence. |
| Conversion | A defined action that indicates progress toward an intended outcome. |
| KPI | A key performance indicator used to assess progress against an objective. |
| Localization | Adapting communication or execution to a specific market while preserving required strategic meaning. |
| Marketing mix | The coordinated set of product, price, place, and promotion decisions. |
| Measurement plan | The agreed definitions, data sources, methods, owners, and cadence used to assess outcomes. |
| Positioning statement | A concise internal articulation of audience, category, differentiation, and reason to believe. |
| RACI | A responsibility model identifying Responsible, Accountable, Consulted, and Informed roles. |
| Reach | The number of unique people exposed to a communication within a defined period and method. |
| Share of voice | A brand's proportion of a defined set of category or media mentions or activity. |
| TAM / SAM / SOM | Total Addressable Market, Serviceable Available Market, and Serviceable Obtainable Market. |
| UTM parameters | URL tags used to identify traffic sources and campaign context in analytics. |

Definitions may vary by organization and measurement system. State the operational definition whenever a metric is used for reporting.

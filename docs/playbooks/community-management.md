# Community Management

## Purpose
Build a useful, safe, and consistent environment for audience interaction.

## Community principles
Set clear participation rules, response expectations, moderation boundaries, privacy practices, and escalation procedures.

## Response framework
Acknowledge the question, clarify the need, provide verified information, and route unresolved cases to the correct team.

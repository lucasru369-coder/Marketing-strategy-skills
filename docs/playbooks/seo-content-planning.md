# SEO Content Planning

## Research
Start with audience tasks and search intent. Group queries by informational, comparative, transactional, and navigational purpose where relevant.

## Plan
1. Map topics to audience needs and journey stages.
2. Review existing content and potential cannibalization.
3. Identify evidence, expertise, and original value needed.
4. Define page purpose, structure, internal links, and CTA.
5. Set technical and accessibility requirements.
6. Measure qualified organic outcomes.

# Conversion Funnel Analysis

## Define the funnel
Choose stages that reflect actual user actions, not merely internal team labels. Define entry, exit, and event rules for each stage.

## Funnel table

## Diagnosis
Segment by relevant device, source, audience, geography, and new/returning status where privacy and sample size allow. Check event implementation before interpreting drop-off.

Look for friction, missing information, performance problems, and mismatched expectations. Do not assume every drop-off is a failure; some users may have completed the task elsewhere.

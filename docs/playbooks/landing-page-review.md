# Landing Page Review

## Review dimensions
Message match, audience relevance, offer clarity, proof, hierarchy, usability, accessibility, mobile behavior, speed, trust, and conversion path.

## Review sequence
1. Confirm the page supports the campaign promise.
2. Check whether the primary action is obvious.
3. Validate claims, prices, availability, and disclaimers.
4. Test forms, links, analytics, and error states.
5. Review mobile and assistive-technology experience.
6. Compare behavior with baseline.

## Findings
| Element | Issue | Evidence | Severity | Recommended change | Owner |
|---|---|---|---|---|---|

Do not optimize conversion by hiding material terms or making cancellation and consent difficult.

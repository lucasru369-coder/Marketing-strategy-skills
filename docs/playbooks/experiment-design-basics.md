# Experiment Design Basics

## Define the test
Write a falsifiable hypothesis, target population, intervention, comparison, primary metric, guardrails, and test duration.

## Design checks
- Randomize at the correct unit where possible.
- Avoid exposing one participant to conflicting variants.
- Estimate sample needs before launch.
- Prevent peeking-driven decisions.
- Check instrumentation and allocation integrity.
- Document exclusions in advance.

## Experiment record
| Hypothesis | Variant | Control | Primary metric | Guardrail | Sample plan | Result |
|---|---|---|---|---|---|---|

If randomization is not possible, describe the quasi-experimental design and its limitations. A positive result is not proof of universal impact.

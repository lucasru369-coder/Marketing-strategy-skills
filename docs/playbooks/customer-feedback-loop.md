# Customer Feedback Loop

## Capture
Collect feedback from appropriate sources such as support themes, research, reviews, community discussions, and structured surveys. Respect consent and data minimization.

## Process
1. Categorize feedback by need, issue, and journey stage.
2. Assess frequency, severity, and audience impact.
3. Route to the accountable product, service, or marketing owner.
4. Communicate decisions where appropriate.
5. Verify whether changes improve the experience.

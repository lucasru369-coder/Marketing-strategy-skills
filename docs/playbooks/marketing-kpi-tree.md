# Marketing KPI Tree

## Build the tree
Start with the business outcome, then identify the customer or commercial drivers that plausibly influence it. Break drivers into measurable components only where data exists.

## Example structure
Revenue → number of customers × average revenue per customer. Customer growth → qualified reach × conversion rate. Retention → active customers × repeat rate.

## KPI tree
| Level | Metric | Definition | Driver relationship | Data source | Owner |
|---|---|---|---|---|---|

Check that formulas are valid and metrics are not double-counted. Label leading indicators separately from lagging outcomes. Treat the tree as a hypothesis to validate.

# Project Scope Control

## Baseline
Document objectives, deliverables, exclusions, acceptance criteria, budget, timeline, and decision rights before execution.

## Change process
1. Describe the requested change and reason.
2. Assess impact on value, effort, cost, timing, risk, and dependencies.
3. Identify options: accept, trade scope, defer, or reject.
4. Obtain approval from the correct owner.
5. Update the baseline and notify affected teams.

## Change log
| Request | Impact | Options | Decision | Approver | Baseline updated |
|---|---|---|---|---|---|

Do not treat every clarification as scope creep. Use proportional controls for small changes and formal approval for material ones.

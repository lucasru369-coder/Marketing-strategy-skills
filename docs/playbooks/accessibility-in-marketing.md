# Accessibility in Marketing

## Content
Use clear language, meaningful headings, captions/transcripts, descriptive link text, and alternative text for informative images.

## Visual design
Check contrast, text size, reading order, motion sensitivity, color dependence, and responsive behavior.

## Experiences
Ensure forms are labeled, errors are understandable, keyboard navigation works, and interactive elements have clear states.

## Review
| Asset/touchpoint | Accessibility check | Issue | Severity | Fix owner | Verified |
|---|---|---|---|---|---|

Include accessibility in briefs and QA from the start rather than treating it as a final polish step. Follow applicable standards and local requirements.

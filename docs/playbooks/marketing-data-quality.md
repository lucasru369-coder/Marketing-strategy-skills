# Marketing Data Quality

## Quality dimensions
Accuracy, completeness, consistency, timeliness, validity, uniqueness, and lineage.

## Checks
- Compare key totals with trusted source systems.
- Validate event names and required properties.
- Detect missing, duplicated, or out-of-range values.
- Confirm time zones, currency, and identity rules.
- Monitor freshness and pipeline failures.

# KPI Selection Guide

Start with the objective. Select metrics that represent the desired outcome rather than the easiest available data.

## Metric layers
- Outcome: business or behavior change
- Leading indicator: early signal of progress
- Diagnostic: helps explain performance
- Guardrail: detects unintended consequences

Validate definition, data source, owner, cadence, segmentation, and limitations. Avoid mixing incompatible denominators or attribution windows.

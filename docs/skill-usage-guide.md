# Skill Usage Guide

This repository contains independent, reusable marketing workflow skills. Each skill can be used on its own or combined with others.

## Skill directory

| Skill | Use it when | Typical output |
|---|---|---|
| `marketing-research` | You need to understand a market, audience, or category | Research brief, evidence log, opportunity areas |
| `competitor-analysis` | You need to compare competitors and alternatives | Competitive landscape, comparison matrix, strategic implications |
| `brand-strategy` | You need to define or refine a brand's strategic direction | Positioning, value proposition, messaging principles |
| `marketing-localization` | You need to adapt a strategy for a specific market | Localization brief, cultural and channel considerations |
| `campaign-strategy` | You need to plan a specific campaign | Campaign brief, audience journey, channel and creative plan |
| `marketing-planning` | You need to coordinate annual or quarterly priorities, budget, and timing | Annual plan, quarterly roadmap, budget and calendar |

## Suggested workflows

### Build a strategy from research
1. Start with `marketing-research` to frame the market and audience.
2. Use `competitor-analysis` to identify alternatives and points of difference.
3. Use `brand-strategy` to turn evidence into positioning and messaging.
4. Use `marketing-localization` when the strategy needs market adaptation.
5. Use `campaign-strategy` to translate the strategy into an executable campaign.
6. Use `marketing-planning` to place initiatives into a wider roadmap and budget.

### Plan first, then execute
1. Use `marketing-planning` to define objectives, priorities, budget envelopes, and timing.
2. Use `campaign-strategy` to develop the selected initiatives.
3. Apply `marketing-localization` for market-specific requirements.
4. Return to the planning templates to track milestones, owners, and outcomes.

## How to invoke a skill

Provide the skill name, context, objective, constraints, and desired output. Share only information that is appropriate for the intended environment.

A useful request format:

> Use [skill name] to help with [objective].
> Context: [approved, non-sensitive background]
> Audience or market: [scope]
> Constraints: [budget, timing, channels, requirements]
> Output: [format and level of detail]

## Working principles

- Start with the smallest skill that solves the immediate problem.
- Combine skills only when the workflow genuinely crosses disciplines.
- Separate verified facts, assumptions, and recommendations.
- Cite sources for external claims and record research dates.
- Mark illustrative examples and synthetic figures clearly.
- Do not include confidential, personal, or customer-identifying information in reusable examples.
- Treat outputs as decision support; validate assumptions with relevant stakeholders.

# Contribution Guide

Contributions should improve the usefulness, clarity, or reliability of the skills and supporting tools.

## Good contributions

- A focused workflow that solves a recurring marketing problem.
- A template that makes an existing workflow easier to apply.
- A clearly labeled fictional example that demonstrates a method.
- A correction backed by a reliable source or reproducible test.
- A script that automates a narrow, well-defined task.

## Before submitting

1. Identify the user problem the change solves.
2. Check whether an existing skill or template already covers it.
3. Keep the change focused and avoid duplicating guidance.
4. Use fictional or appropriately anonymized examples.
5. Remove personal, confidential, and customer-identifying information.
6. Add tests for executable behavior.
7. Check links and instructions affected by the change.

## Skill authoring checklist

- State the purpose and intended use.
- Specify required inputs and expected outputs.
- Explain the workflow in a usable order.
- Distinguish facts, assumptions, and recommendations.
- Include quality checks and limitations.
- Link to relevant templates rather than duplicating long content.

## Commit guidance

Use a short, action-oriented commit message, such as:

- Add campaign brief template
- Clarify localization review checklist
- Test budget allocator input validation

Prefer small commits that describe real, reviewable changes. Do not create empty commits or split an unchanged file into artificial edits to inflate activity.

## Privacy and security

Never commit credentials, access tokens, private correspondence, personal records, internal business data, or unapproved customer information. Review the complete diff before publishing.

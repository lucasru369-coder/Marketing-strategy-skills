# Brand Promise Development

## Definition
A brand promise is the consistent value an audience should expect across product, service, communication, and experience.

## Development steps
1. Identify the audience and meaningful need.
2. Define the outcome the brand can reliably deliver.
3. Gather proof from capabilities, product experience, and behavior.
4. Compare the promise with category conventions and alternatives.
5. Test clarity, relevance, credibility, and distinctiveness.
6. Translate the promise into experience principles.

## Promise test
| Criterion | Question | Evidence |
|---|---|---|
| Relevant | Does it matter to the audience? | |
| Credible | Can the organization deliver it? | |
| Distinctive | Is it meaningfully different? | |
| Consistent | Can every touchpoint support it? | |

Avoid promises that depend on capabilities the organization cannot sustain.
